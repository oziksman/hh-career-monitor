# Данные и границы доступа

- API-ключи хранятся локально как Windows DPAPI XML для текущей учётной записи. Это не защита от программы, уже работающей под тем же пользователем.
- Mistral получает текст вакансии и `src/profile-summary.txt` только при анализе. Telegram получает уведомления и результаты. Проверьте условия обработки данных выбранных сервисов самостоятельно.
- PDF читается локально; браузер HH хранит cookies в `src/monitor-browser/`.
- MCP-инструмент PDF имеет доступ к указанным локальным файлам с правами процесса. Подключайте сервер только к доверенному клиенту.
- Страницы вакансий считаются недоверенными данными. Промпт не даёт абсолютной защиты от prompt injection.
- Не публикуйте `src/*.xml`, `src/*.json`, профили кандидата, cookies, логи с персональными данными или пользовательские PDF. `.gitignore` предотвращает обычное добавление, но не отменяет `git add -f` и не очищает прошлую историю.
- Не вставляйте токены в issue, скриншоты или сообщения об ошибках. При утечке отзовите ключ у провайдера.
- Бот должен быть отдельным, без второго потребителя `getUpdates` и без webhook. Нажатия разрешены только настроенному пользователю в его личном чате.

При описании ошибки прикладывайте обезличенные шаги воспроизведения и код HTTP, без секретов и содержимого резюме. Никогда не публикуйте действующий секрет для демонстрации проблемы.

HH Monitor · Windows x64

1. Распакуйте весь ZIP в свою папку (например, Документы\HH-Monitor). Запустите HH-Monitor.exe из распакованной папки. Нужны интернет и установленный Google Chrome или Microsoft Edge. Node.js уже внутри.

2. В панели нажмите «Настроить Telegram». По ссылке откройте @BotFather, отправьте /newbot и создайте своего бота. Вставьте выданный токен в скрытое поле панели → «Проверить токен». Откройте бота именно по ссылке из панели, нажмите Start («Запустить») в Telegram. Вернитесь в панель → «Подключить и отправить проверку». Убедитесь, что сообщение пришло в ваш личный чат.

3. В обычном браузере откройте HH, выставьте свои фильтры или выберите рекомендации по своему резюме. Скопируйте адрес страницы поиска (hh.ru/search/vacancy?...), вставьте в поле панели → «Сохранить ссылку». Монитор использует выдачу за последние сутки.

4. Для рекомендаций по резюме откройте «Вход в HH.cmd» до запуска мониторинга. В появившемся окне войдите в свой аккаунт HH, убедитесь, что видите свою выдачу, и закройте окно браузера. Монитор запомнит этот вход. Для общедоступного поиска вход необязателен.

5. Нажмите «Запустить». Дождитесь времени первой успешной проверки и числа вакансий. Первый список запоминается без рассылки. Затем монитор каждые 15 минут присылает новые и переопубликованные вакансии. Закрытие панели не останавливает проверки. После перезагрузки ПК откройте панель и нажмите «Запустить». Для остановки используйте «Пауза».

Уведомления работают без ключа нейросети. Для кнопки анализа нужны отдельно настроенные профиль кандидата и модель. Если HH попросит войти повторно, нажмите «Пауза», дождитесь завершения проверки, повторите шаг 4 и запустите монитор.

Пересылайте исходный ZIP: после настройки в распакованной папке появятся ваш профиль браузера и локальные настройки Telegram.

# Анализ вакансий через OpenCode

Адаптер использует официальный CLI OpenCode и только модель
`opencode/glm-5.3-flash-free`. Для исчерпанной квоты можно включить
независимый резерв Mistral Free; платные тарифы автоматически не включаются.

В `src/analysis-model.json`:

```json
{
  "provider": "opencode",
  "model": "opencode/glm-5.3-flash-free",
  "fallback": {
    "provider": "mistral",
    "model": "ministral-14b-2512",
    "freeTierConfirmed": true
  },
  "executable": "C:/absolute/path/opencode.exe",
  "runtime": "C:/absolute/path/isolated-runtime"
}
```

Включайте `freeTierConfirmed` только после проверки Free и отключённого
API pay-as-you-go в Mistral Admin. Модель сама по себе не бесплатная на любом
тарифе: используются включённые квоты Free. Если меняете тариф или включаете
платное превышение, отключите резерв или пересмотрите бюджет заранее.
Ключ остаётся в существующем `mistral-token.xml` с защитой Windows DPAPI.

При `OPENCODE_FREE_QUOTA` резерв получает тот же обезличенный профиль и текст
вакансии. На час OpenCode исключается из запросов (состояние сохраняется в
`analysis-provider-state.json`), затем автоматически проверяется снова.
Готовый результат сохраняет фактического провайдера в `analysisProvider`.
Если оба сервиса недоступны, задание остаётся в очереди. Ошибки настроек
и проверки формата GLM не запускают этот резерв автоматически.

Профиль для отправки хранится в `src/profile-analysis.txt`. Удалите ФИО,
контакты и прочие ненужные для оценки данные до включения облачного анализа.
Файл игнорируется Git. Передача профиля облачной модели требует согласия владельца.

После смены провайдера перезапустите единственный процесс монитора.
Кнопка «Проанализировать» сохраняется. Каждый запрос создаёт отдельную
сессию OpenCode. Локальные сессии и настройки находятся под `runtime`;
автоматическая публикация сессий отключена. Для инструментов требуется
подтверждение; анализ передаёт весь нужный текст и не требует инструментов.

При ошибках доступа, квоты или таймауте задание остаётся в очереди.
Повтор: через 5, 10, 20, 40, затем 60 минут. Уведомление о сбое отправляется
один раз для каждого типа ошибки задания. При сообщении OpenCode
`Free usage limit reached` повтор откладывается на час; это интервал проверки,
а не обещание восстановления квоты. Ошибка квоты распознаётся сразу из потока
ошибок CLI. Готовый ответ извлекается по событию завершения генерации, без
ожидания завершения всего процесса CLI. Мониторинг новых вакансий использует прежнюю логику.
Ошибка отправки готового результата не запускает генерацию повторно.

Для возврата на Mistral восстановите прежний `analysis-model.json`, например
`{"model":"ministral-14b-2512"}`; сохранённый ключ Mistral не удаляется.

Проверки: `npm test`. Доступность модели в каталоге не гарантирует успешный
запрос: перед включением необходим отдельный сетевой тест и проверка качества.
